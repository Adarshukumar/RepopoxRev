# Vendored source: Mochy Music

The `Mochy-Music/` directory in this repository is a **verbatim copy of the working tree** of
[realidkroo/Mochy-Music](https://github.com/realidkroo/Mochy-Music), taken at upstream commit:

```
8dd8f3b0620473ab4c26466f3b6b8b7d08aaab12
```

relicensed. The only things removed when copying were the upstream `.git/` directory (179 MB of
history) and build outputs.
